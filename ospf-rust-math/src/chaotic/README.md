# chaotic

:us: English | :cn: [简体中文](README_ch.md)

## Overview

This module provides chaotic systems and iterative maps, including 48+ attractors, 19 2D maps, 14 scalar maps, and special systems. All systems are generic over `S: Field + Float`, defaulting to `f64`.
