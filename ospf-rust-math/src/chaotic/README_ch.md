# chaotic

:us: [English](README.md) | :cn: 简体中文

## 概述

本模块提供混沌系统与迭代映射，包含 48+ 吸引子、19 个二维映射、14 个标量映射和特殊系统。所有系统均基于泛型 `S: Field + Float`，默认为 `f64`。

## 系统

### 3D 系统（基于 Point3）— 48 个系统

Aizawa, Anishchenko-Astakhov, Arneodo, Biology, Bouali, Burke-Shaw, Capacitance, Chen, Chen-Celikovsky, Chen-Lee, Chua Attractor, Chua Circuit, Coullet, Coupled Lorenz, Dadras, Dequan Li, Duffing Equation, Finance, Four-Wing, Genesio-Tesi, Hadley, Halvorsen, Hindmarsh-Rose, Liu-Chen, Lorenz, Lorenz84, Lorenz Attractor, Lorenz Mod1, Lorenz Mod2, Lu-Chen Attractor, Lu-Chen System, Newton-Leipnik, Nose-Hoover, Qi-Chen, Rabinovich-Fabrikant, Rayleigh-Benard, Rossler, Rucklidge, Sakarya, Shimizu-Morioka, Thomas, Thomas Cyclically Symmetric, TSUCS1, TSUCS2, Wang-Sun, Wimol-Banlue, Yu-Wang

### 4D 系统（基于 Point4）— 3 个系统

Four-Scroll Hyper-Chaotic, Lorenz-Stenflo, Qi Attractor

### 2D 系统（基于 Point2）— 19 个系统

Arnold's Cat Map, Baker's Map, Bogdanov, Brusselator, Circuit, Complex Quadratic, Complex Squaring, Duffing Map, Gingerbreadman, Henon, Ikeda, Kaplan-Yorke, Kicked Rotator, Lozi, Lotka-Volterra, Martin, Symplectic, Tinkerbell, Van der Pol

### 标量映射 — 14 个映射

Arnold Tongue, Chebyshev, Circle, Dyadic, Exponential, Gauss Iterated, Gauss, Logistic, Sine, Singer, Sinus, Sinusoidal, Tent, Zaslavskii

### 特殊系统 — 5 个系统

Double Pendulum, Interval Exchange, Lorenz96, N-Body, Newton Iterate
