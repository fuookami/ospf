# 复杂示例总览

第一次使用业务框架时，先看[场景选型与上手教程](/zh-cn/frameworks/)。本组页面用于理解综合业务和上下文模型，不替代最小运行教程；Demo3 可接在 CSP1D 后，Demo4 接在 Gantt 后，Demo5 接在 Network 后阅读。

本页是采用领域驱动设计架构的复杂示例入口。每个 Demo 都有独立总览页，所属有界上下文的数学模型会收纳在该 Demo 的菜单分组下面。
