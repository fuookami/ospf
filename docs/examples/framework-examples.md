# Complex examples overview

This page is the entry point for the DDD-based framework examples. Each demo has its own overview page, and its bounded-context domain models are nested below that demo in the sidebar.

## Demo map

| Demo | Problem | Overview | Context model index |
|---|---|---|---|
| 1 | Service placement | [Framework example 1](framework-example1) | Route and bandwidth contexts are listed in the sidebar |
| 2 | Aircraft cargo load planning | [Framework example 2](framework-example2) | [Demo 2 context index](framework-example2/domain-models) |
| 3 | One-dimensional cutting stock | [Framework example 3](framework-example3) | Material and produce contexts are listed in the sidebar |
| 4 | Flight recovery | [Framework example 4](framework-example4) | [Demo 4 context index](framework-example4/domain-models) |
| 5 | VRPTW branch-and-price | [Framework example 5](framework-example5) | VRP, route generation, and route compilation contexts are listed in the sidebar |

Each context page follows the domain-model template: responsibility and dependencies, concepts, variables, predicates, sets, intermediate values, assertions, constraints, objective, algorithms, ubiquitous language, design decisions, and change log.
